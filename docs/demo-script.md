# Script de demonstração do Copiloto N1

## Objetivo
Mostrar em 5 minutos como o painel transforma uma conversa em chamado validado e pronto para revisão.

## Cenário
Use o modo demo do painel com os cenários:
- impressora
- login
- banco

## Passo a passo
1. Abra o painel executando `copiloto-n1 painel`.
2. Selecione um cenário em "Modo demo".
3. Clique em "Carregar cenário demo".
4. Observe o título, os campos preenchidos e a nota calculada.
5. Edite um campo para testar recalculo dinâmico.
6. Salve em JSON e TXT.
7. Copie o resumo para a área de transferência.
8. Explique o valor: menos retrabalho, melhor qualidade e próxima pergunta sugerida.

## Mensagem de venda
"O Copiloto N1 não substitui o analista; ele reduz a carga operacional e melhora a qualidade do chamado antes do escalonamento."

## Pontos de destaque para a apresentação
- qualidade do registro em tempo real
- explicabilidade das pendências
- exportação para uso em sistemas existentes
- arquitetura pronta para ajuda e integração futura
